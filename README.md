# Autonomous Berean Council KJV Bible Study Loop

An autonomous, verified loop engine designed according to the rigorous principles of **[Loop Engineering: From Zero to Hero](docs/loop-engineering)**, integrating **[Laya](https://github.com/NandhaKishorM/laya)** (non-autoregressive System 1 decision engine) and synthesizing the **KJV 7.2 (Berean Council Flywheel)** and **KJV 8.2 (Reformed Workbook Builder)** skill bundles from **[kjv.prompt](https://github.com/thomasperdana/kjv.prompt)** to generate an in-depth, print-ready, handout-complete Bible study and interactive workbook for all 1,189 chapters of the Holy Bible from Genesis 1 to Revelation 22.

## 2. Synthesis: KJV 7.2 + KJV 8.2 Master Standard

Every chapter study generated by the loop merges the academic breadth of **KJV 7.2** with the pedagogical depth of **KJV 8.2**:

### The 7 Berean Council Scholar Briefs (KJV 7.2)
1. **The Philologist**: Masoretic Hebrew & Textus Receptus Greek underlying the KJV; translation rationale; archaic glosses; distinctive pronoun distinctions (`thee/thou` singular vs. `ye/you` plural).
2. **The Historian**: Ancient Near Eastern / Greco-Roman historical backdrop, geography, customs, politics, covenantal context.
3. **The Literary Scholar**: Literary genre, canonical structure, book-level arguments, repetitions, chiastic parallels, hinge words (`therefore`, `for`, `but God`).
4. **The Theologian**: Reformed covenantal dogmatics, Christological root, Christ as the single source of life and light (John 1:4; 10:10; 8:12).
5. **The Church Historian**: Creeds and confessions (Westminster, 1689 Baptist, Heidelberg), historical commentaries (Augustine, Calvin, Henry, Spurgeon).
6. **The Pastor**: Shepherding application, spiritual warfare, danger points, comfort for troubled consciences.
7. **The Educator**: Small-group engagement, pacing, pedagogical structure.

### The 19-Point Lesson Template & 5-Level Question Ladder (KJV 8.2)
1. **Header & Passage Citation** (KJV exact reference)
2. **The Hook / Opening Scenario** (Modern dilemma bridge)
3. **Historical & Philological Context Brief** (Archaic glosses & original languages)
4. **Literary Structure & Hinge Words** (Unit divisions & connective words)
5. **Verbatim KJV Passage Text** (Canonical chapter text with translator italics noted)
6. **Level 1: Observation Questions** (Facts / Textual details with write-in lines)
7. **Level 2: Interpretation Questions** (Reformed hermeneutics & theological meaning)
8. **Level 3: Application Questions** (Heart-searching conviction & holy living)
9. **Level 4: Christocentric & Humility Questions** (Christ magnified, human pride abased)
10. **Level 5: Life & Light Questions** (Active transmission of Christ's life and truth)
11. **The Berean Council Consensus Briefs** (7 scholar synthesis)
12. **Church History & Confessional Witness** (Confessional standards & historical sermons)
13. **Exhaustive Systematic Doctrinal Summarization**:
    - **Command**: *summarize in great details the doctrines for the chapter*
    - Covers all 9 heads: (1) Theology Proper, (2) Christology, (3) Pneumatology, (4) Anthropology, (5) Hamartiology, (6) Soteriology, (7) Ecclesiology, (8) Eschatology, (9) Sanctification & Christian Living.
    - Each unpacked with: (a) Doctrinal Proposition, (b) Textual Exegesis, (c) Verbatim KJV Cross-References, (d) Counterfeits & Opposing Errors Refuted, (e) Practical / Pastoral Bearing.
14. **Three Concrete Humility Practices** (Actionable tips, tricks, and daily hacks)

## 3. Laya System 1 Decision Engine Integration

In a massive loop spanning 1,189 chapters, evaluating prose quality and doctrinal consistency via full autoregressive LLM calls is expensive and slow. **Laya** (`https://github.com/NandhaKishorM/laya`) operates as a sub-50ms non-autoregressive evaluator:

- **Doctrinal Soundness (`score`)**: Evaluates depth and orthodoxy (`unacceptable`, `superficial`, `sound and deep`).
- **KJV Faithfulness (`noul`)**: Computes probability that the text faithfully adheres to King James Version Scripture without paraphrases or modern translations.
- **Life & Light Practicality (`choice`)**: Classifies whether action points are `absent`, `vague`, or `actionable` with fill-in tables.
- **Humility Posture (`choice`)**: Validates that Christ is exalted and human pride is abased (`self_reliant`, `mixed`, `christ_magnifying`).

## 4. Loop Engineering Guardrails & Stop Rules

Conforms to the 5 Stop Families defined in Level 3 of *Loop Engineering: From Zero to Hero*:

| Stop Family | Trigger Condition | Loop Behavior |
|---|---|---|
| **DONE** | All 3 checkers exit 0 (Verse check 100%, Structure 19/19, Laya approved). | Saves chapter to `studies/{OT\|NT}/...`, updates `progress/progress.json`, logs `DONE`, advances to next chapter. |
| **CAP** | 3 failed iterations on the same chapter; or timeout. | Stops retrying chapter, logs escalation in `progress/escalations.md`, marks chapter `failed`, and continues (or halts if `--halt-on-error`). |
| **STUCK** | Identical verification failure signature 3 times consecutively. | Halts chapter, logs `STUCK` in run log, files escalation report. |
| **DANGER** | Protected files modified (`data/kjv.json`, `prompts/`, `verifier/`). | Aborts loop execution immediately with exit code 5. |
| **HUMAN** | `.loop-stop` sentinel file exists in workspace root. | Gracefully halts loop after current iteration with exit code 4. |

## 6. How to Run

### Safe Dry-Run (Zero API Spend)
Test the entire loop lifecycle, stop rules, and checkers safely:
```bash
./scripts/run_loop.sh --ref "Genesis 1" --dry-run
```

### Run a Single Chapter
```bash
./scripts/run_loop.sh --ref "Romans 8"
```

### Run an Entire Book
```bash
./scripts/run_loop.sh --book "Ephesians"
```

### Run a Testament
```bash
./scripts/run_loop.sh --testament "NT"
```

### Run the Entire Bible (Genesis 1 to Revelation 22)
Runs autonomously with state persistence across interruptions:
```bash
./scripts/run_loop.sh --all
```

### Gracefully Pausing the Loop
Create the `.loop-stop` file in the root directory:
```bash
touch .loop-stop
```
The loop will finish its current chapter cleanly, update the state, and pause with exit code 4 (`HUMAN`). To resume, remove `.loop-stop` and re-run.
